**Extreme minimalism. Everyday comfort.**

Serein for Telegram Desktop brings the calming, warm Serein color palette to your everyday messaging app. Say goodbye to oversaturated chat bubbles and jarring white/black backgrounds:

- **Serein Alabaster (Light):** Gentle ivory surfaces with soft beige chat bubbles for pleasant daytime messaging.
- **Serein Obsidian (Dark):** Warm charcoal canvas with muted rose accents for peaceful nighttime communication.

## Key Highlights

- **Low-Distraction Chat Bubbles:** Distinguishes incoming and outgoing messages with calm tonal balance rather than vibrant colors.
- **Matching Chat Wallpapers:** Includes custom clean background images (`background-alabaster.png` and `background-obsidian.png`).
- **Native `.tdesktop-theme` Format:** 100% compatible with official Telegram Desktop on Windows, macOS, and Linux.

---

## Installation

1. Download the latest release from the [Releases page](https://github.com/cmduyeen/serein-telegram/releases/latest).
2. Open Telegram Desktop.
3. Go to **Settings → Chat Settings**.
4. Click the three dots menu (top right) and choose **Choose from file...** (or drag and drop the `.tdesktop-theme` file into Telegram).
5. Select `alabaster.tdesktop-theme` or `obsidian.tdesktop-theme`.
6. Preview the theme and click **Apply Theme**.

## Honest Design & Limitations

Themes are aesthetic preferences and visual comfort tools, not medical treatments. Serein has not been clinically tested to treat eye strain. Ambient lighting, glare control, and regular breaks remain essential.
- [American Academy of Ophthalmology: Computer Usage Guidance](https://www.aao.org/eye-health/diseases/computer-usage)
